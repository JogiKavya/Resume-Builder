
🎯 Interactive Resume Builder

This project is a simple and elegant **interactive resume builder** built using HTML, CSS, and JavaScript. It allows users to enter their personal and professional details, dynamically preview the resume, and download it as a **PDF**.

✨ Key Features

* Real-time preview of resume content
* Add multiple **education**, **experience**, and **skills** entries
* Download resume as a **PDF** using jsPDF
* Clean and responsive design with a background image
* User-friendly form with validation and animated inputs
* Option to clear the form and reset all fields

💡 Technologies Used

* **HTML** – Structure of the web page
* **CSS** – Styling and responsiveness
* **JavaScript** – Logic for dynamic preview and interactivity
* **jsPDF Library** – For exporting the resume as a downloadable PDF

🧾 How It Works

1. User enters details like name, email, phone, and profile summary.
2. Additional information like education, experience, and skills can be added through prompt boxes.
3. The preview updates in real-time based on the input.
4. A PDF of the resume can be downloaded with one click.
5. Form can be cleared any time to start over.
